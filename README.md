# Demo Image List Starter

A Next.js image list that displays image titles and links to their source pages.

## Getting Started

- Set up a new project

```bash
npx create-next-app my-image-list -e https://github.com/colbyfayock/demo-image-list-starter
```

- Navigate to your new project

```bash
cd my-image-list
```

- Start the development server

```bash
npm run dev
```
